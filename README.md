# TradePath IL — ערכת בנייה ל-Claude Code

מערכת למידה אינטראקטיבית בעברית (RTL) שלוקחת אדם שלא סחר מעולם, שלב אחרי שלב, עד סוחר שעובד לפי תוכנית כתובה, מנהל סיכונים ומתעד כל עסקה.
"TradePath IL" הוא שם עבודה. אפשר להחליף אותו בקובץ `CLAUDE.md`.

**המערכת היא לימודית בלבד.** היא לא מתחברת לברוקר, לא מבצעת עסקאות בכסף אמיתי ולא נותנת המלצות קנייה או מכירה.

קובצי ההנחיה ל-Claude Code כתובים באנגלית כי כך הם עובדים הכי אמין. כל מה שהלומד רואה כתוב בעברית.

## מה צריך לפני שמתחילים

- Node.js בגרסת LTS ו-Git
- Claude Code מותקן ומחובר (תיעוד: https://code.claude.com/docs)
- פרויקט Supabase חדש (ריק)
- חשבון Vercel (לפאזה 8)
- מפתח API של Twelve Data, תוכנית חינמית (נתוני המחירים לסימולטור, מפאזה 5)
- אופציונלי: מפתח Anthropic API (המורה הפרטי, פאזה 8)

## סדר העבודה

1. **חלץ את ה-ZIP** לתיקייה ריקה, פתח בה PowerShell והרץ `git init`.
2. **עיצוב (מומלץ):** הדבק את `docs/07-DESIGN-BRIEF.md` ב-Claude Design, ושמור את התוצרים בתיקייה `design/` בפרויקט.
3. **התקן סקילים:** `.\scripts\install-skills.ps1`. עבור פעם אחת על קובצי ה-`SKILL.md` שהותקנו ב-`.claude\skills` לפני השימוש.
4. **הרץ `claude`** בתיקייה, ואז `/build-phase 0`. Claude Code יקים את השלד, יריץ בדיקות וידווח בעברית.
5. **עבור על הדיווח**, בדוק ידנית מה שהוא מבקש, ורק אז `/build-phase 1`. כך עד פאזה 8.
6. **תוכן:** `/new-lesson s1-m1-l2` כותב שיעור אחד מהתוכנית, כולל מבחן, כרטיסיות ובדיקת בהירות. `/status` מראה מה חסר.
7. **לפני כל שלב לימודי חדש:** `/fact-check all-volatile` מאמת מחדש עובדות שמשתנות (מס, רגולציה, שעות מסחר).

## כמה זמן זה ייקח ללמוד

בקצב של 2–3 שעות בשבוע: כ-40 שבועות לשיעורים (שלבים 0–6), ואחריהם לפחות 12 שבועות מסחר דמו (שלב 7). כלומר קצת יותר משנה עד שהמערכת "מאשרת" לשקול כסף אמיתי. זה מכוון: רוב מי שמדלג על השלבים האלה מפסיד.

שבוע טיפוסי: שני שיעורים של 20–25 דקות, תרגול אחד של 45 דקות, ו-15 דקות כרטיסיות חזרה.

## מה חשוב לדעת על הערכה

- **הערכה לא הורצה.** היא אפיון והנחיות; פאזה 0 תחשוף התאמות שצריך (גרסאות ספריות, בחירת ספריית MDX).
- **העובדות ב-`docs/08-SOURCES.md` נכונות ל-4.10.2026** וחלקן ממקורות משניים. הסוכן `fact-checker` מונחה להחליף אותם במקורות ראשוניים (רשות ניירות ערך, הבורסה, רשות המסים, FINRA).
- **מס ורגולציה הם מידע כללי, לא ייעוץ.** לפני פתיחת חשבון אמיתי כדאי לדבר עם רואה חשבון.
- **הדמו הוא שלנו.** הסימולטור מציג מחירי אמת בהשהיה של 8 שבועות, עם מינוף, בטוחות, פקודות עתידיות, סטופ נגרר ועמלת לילה. המרווחים, המינוף והעמלות בו הם ערכי הדגמה, ולא התנאים של ברוקר כלשהו. הנימוק לבחירת מקור המחירים נמצא בתחילת `docs/10-SIMULATOR.md`.
- **הסגנון עדיין פתוח.** שלבים 0–4 משותפים לכל הסגנונות. בשלב 5 טועמים את כולם ובוחרים. שים לב שעם 2–3 שעות בשבוע, מסחר יומי כמעט לא מעשי; המערכת תגיד את זה בשאלון ההתאמה.
